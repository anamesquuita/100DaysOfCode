# 🐍 100 Days of Python

Este repositório reúne os projetos que estou desenvolvendo durante o curso **100 Days of Python**.

A ideia é praticar Python todos os dias, aprender novos conceitos e acompanhar minha evolução ao longo dos 100 dias.

## 📚 O que estou aprendendo

Durante o curso, vou trabalhar com conceitos como:

- 🐍 Fundamentos de Python
- 🔀 Condicionais e loops
- 📦 Estruturas de dados
- 🧩 Funções
- 🗂️ Arquivos e módulos
- 🐛 Tratamento de erros
- 🏗️ Programação Orientada a Objetos
- 🌐 APIs e desenvolvimento web
- 🗄️ Banco de dados
- 🤖 Automação
- E muito mais!

## 📅 Projetos

| Dia | Projeto | Conceitos aprendidos |
|---:|---|---|
| 01 | Gerador de Nome de Banda | Variáveis, impressão, entrada de dados e manipulação de strings |
| 02 | Calculadora de Gorjetas | Tipos de dados, conversão de tipos, operações matemáticas e f-strings |
| 03 | Ilha do Tesouro | Estruturas condicionais e operadores lógicos |
| 04 | Pedra, Papel e Tesoura | Aleatoriedade e listas |
| 05 | Gerador de Senhas | Loops, range e listas |
| 06 | Reeborg's World | Funções, blocos de código, loops e resolução de problemas |
| 07 | Jogo da Forca | Loops, listas, strings e importação de módulos |


## 🎯 Objetivo

Completar os 100 dias e, principalmente, **evoluir na prática**. 🚀

Cada projeto é uma oportunidade para aprender algo novo, testar ideias e melhorar meu código.
