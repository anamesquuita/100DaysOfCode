# 🐍 100 Days of Python

Este repositório reúne os projetos que estou desenvolvendo durante o curso **100 Days of Python**.

A ideia é praticar Python todos os dias, aprender novos conceitos e acompanhar minha evolução ao longo dos 100 dias.

## 📚 O que estou aprendendo

Durante o curso, vou trabalhar com conceitos como:

- 🐍 Fundamentos de Python
- 🔀 Condicionais e loops
- 📦 Estruturas de dados
- 🧩 Funções
- 🗂️ Arquivos e módulos
- 🐛 Tratamento de erros
- 🏗️ Programação Orientada a Objetos
- 🌐 APIs e desenvolvimento web
- 🗄️ Banco de dados
- 🤖 Automação
- E muito mais!


## 🎯 Objetivo

Completar os 100 dias e, principalmente, **evoluir na prática**. 🚀

Cada projeto é uma oportunidade para aprender algo novo, testar ideias e melhorar meu código.
